GitHub Pages + Cloudflare Setup

Step-by-step tutorial to link your Ebice website code with GitHub Pages and Cloudflare Custom Domain:

  1. Upload file to GitHub:

    Rename this file to index.html, upload it to your GitHub repository root folder, and commit.

  2. Enable GitHub Pages:

    Go to Repository Settings > Pages. Select main branch and click Save.

  3. Set Custom Domain in GitHub:

    In GitHub Pages settings, under "Custom domain", enter your domain name (e.g. ebice.com) and save. This generates a CNAME file automatically.

  4. Configure Cloudflare DNS:

    In Cloudflare dashboard, go to DNS > Records and add:

    • CNAME for @ pointing to yourusername.github.io (Proxy enabled - Orange Cloud).
    • CNAME for www pointing to yourusername.github.io.
  5. SSL/TLS Settings on Cloudflare:

    Set SSL/TLS encryption mode to Full or Flexible in Cloudflare to avoid redirection loop errors.
